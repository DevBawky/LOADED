# 현지화 문구 가이드

탄환과 유물 설명은 짧은 효과 문구를 줄 단위로 나열한다. 완전한 서술문보다
`조건 → 대상 → 효과 → 수치` 순서를 우선한다.

## 표준 용어

| 사용 | 사용하지 않음 |
| --- | --- |
| 피해 | 대미지, 데미지 |
| 기본 피해 | 기본 대미지 |
| 최종 피해 | 최종 대미지, 최종대미지 |
| 치명타 | 크리티컬 |
| 치명타 확률 | 크리티컬 확률 |
| 치명타 배율 | 크리티컬 배율 |
| 턴 소모 없음 | 턴을 소모하지 않습니다 |
| 재발사, 추가 발사 | 다시 발사합니다, 한 번 더 발사합니다 |
| 관통 N회 | 적 N명 관통 |

확률의 퍼센트 변화는 `%p`, 피해 증가나 배율 변화는 `%` 또는 `xN`으로
표기한다.

## 문장 형식

- 발동 조건은 `명중 시`, `치명타 시`, `적 처치 시`, `발사 시`,
  `재장전 시`로 통일한다.
- 확률은 효과 뒤에 괄호로 쓴다. 예: `관통 1회 (50%)`.
- 서로 다른 효과는 줄바꿈으로 분리한다.
- 수치 변화는 `대상 +수치` 또는 `대상 -수치`로 쓴다.
- 설명 끝의 마침표와 불필요한 존댓말 종결어미는 생략한다.

```text
적 처치 시 최대 체력 +1 (50%)
관통 1회 (30%)
재장전 시 턴 소모 없음
```
