# 탄환과 현지화 스프레드시트

## 파일과 도구

- `outputs/authoring-20261002/LOADED_BulletData.xlsx`
- `outputs/authoring-20261002/LOADED_Localization_ko_en.xlsx`
- Unity 메뉴 `Tools > LOADED > Bullet Balance`
- Unity 메뉴 `Tools > LOADED > Localization Workbook`

워크북을 저장한 뒤 도구에서 **검증 · 변경 미리보기**를 실행한다. 적용할
에셋이나 문구를 선택하고 **선택한 변경 적용**을 누른다. 파일을 저장하는
것만으로 Unity가 변경되지는 않는다. 적용 후 계속 편집하려면 현재 데이터를
새 워크북으로 내보낸다. 이전 워크북으로 다른 사람의 변경을 덮어쓰는 것은
검증 단계에서 차단한다.

노란 셀은 입력값, 회색 셀은 식별·참조 정보다. 필터와 첫 행 고정으로 찾을 수
있다. 식별키는 탄환 이름이나 중복 가능한 `bulletId`가 아니라 Asset GUID와
레벨이다. 데이터 셀의 수식은 허용하지 않는다. Excel에서 계산했다면 값으로
붙여넣고 가져온다. Excel이 저장 중인 파일, 외부 링크 그림, 중복 행은 거부한다.

## 탄환 편집

| 시트 | 편집 대상 |
| --- | --- |
| 표준형·유령형·저격형·폭풍형·산탄형·관통형·상태이상형·기동형·연계형·경제형·성장형·혈투형 | 유형별 페이지. Normal → Rare → Ace → Legendary 등급 구역 안에 탄환별 기본·+1·+2·+3 스탯과 설명을 네 줄로 배치 |
| 아이콘 | 아이콘 교체 전용. 이름·유형·등급은 조회 정보 |
| 효과 | 레벨별 효과 종류·대상·확률·스택·이동 거리·수치·전이율 |
| 조건 | 조건부 효과 묶음의 발동 조건 |
| 관통 | 각 관통 단계의 성공 확률 |
| 초월 준비 | 초월 단계별 성공 확률·비용·메모 |
| 메타데이터 | 스키마, 프로젝트 식별, 내보내기 당시 원본과 아이콘 해시 |

효과·조건·관통의 번호는 **0부터 연속**이다. 효과의 조건 번호 `-1`은 일반
효과이며, 나머지는 조건 시트의 해당 묶음을 참조한다. 효과 행 삭제는 실제
효과 삭제로 취급하므로 변경 미리보기를 확인한다. 필수 레벨 행 삭제는 거부한다.
강화 레벨의 산탄 발수 `0`은 기존 `BulletData` 규칙대로 기본 발수를 상속한다.
현재 저장 데이터에서 사용하지 않는 효과의 스택·이동 거리는 `0`일 수 있다.

유형 페이지 상단에는 해당 유형의 전투 역할을 설명하는 안내 문구가 있으며,
열은 아이콘·이름·등급·설명 다음에 레벨별 능력치가 이어진다. 탄환 행은 Normal은
밝은 회색, Rare는 밝은 파랑, Ace는 밝은 금색, Legendary는 밝은 보라 배경으로
구분한다. 저격형은 끊어진 조준경 코너와 중앙 눈금, 경제형은 동전 같은 이중
외곽선, 혈투형은 모서리 대각 가시 문양으로 탄환별 네 레벨 묶음을 구분한다.
세 문양은 동일한 중립색 선을 사용하고 표준형은 기존 표현을 유지한다.
치명타 배율은 소수 셋째 자리에서 반올림해 둘째 자리까지 표시한다.

유형 페이지의 입력 셀에서 피해·사거리·치명타·발수·턴 소모·반동·강화비용·설명을
편집한다. 이름·등급·구매 가격은 기본(0) 행에서만 편집한다. 아이콘과 식별 정보는
잠겨 있으며 GUID 열과 내부 메타데이터 탭은 숨긴다. 좌측 네 열과 머리글을 고정한다.
페이지 분류는 현재 게임의 `BulletType` 기준이며, 이름이 비슷해도 현재 표준형으로
설정된 탄환을 임의로 다른 유형으로 바꾸지는 않는다. 등급을 바꾼 후 다시 내보내면
해당 등급 구역으로 재정렬된다. 이전 v1 워크북 가져오기도 유지한다.

스탯을 적용하면 실제 게임이 읽는 `BulletData`와 강화 레벨 데이터가 바뀐다.
`BulletInstance`는 해당 레벨의 값을 조회한다. Excel 저장만으로 자동 적용되지
않으며, 기존 배포 빌드에는 새로 빌드해야 반영된다. 설명을 바꾸는 것만으로 새로운
능력 코드가 구현되지는 않는다.

### 아이콘

1. **아이콘** 시트 **A열의 기존 그림**을 선택한다.
2. Excel의 **그림 변경**으로 PNG/JPEG를 교체한다.
3. 그림의 왼쪽 위가 해당 탄환의 A열 셀 안에 있도록 유지한다.
4. 저장 후 Unity에서 검증하고 적용한다.

셀 위에 배치하는 포함된 그림을 지원한다. 최신 Excel의 **셀 안에 배치**,
`IMAGE()` 수식, 외부 URL 그림은 지원하지 않는다. 한 행에는 그림 하나만
있어야 한다. 행 정렬 후에도 그림이 같은 탄환 행을 따라갔는지 확인한다.
유형별 페이지의 그림은 내보내기 시점의 읽기 전용 미리보기다. Excel 시트 보호로
교체를 막으며, 보호를 해제하고 그림을 바꿔도 Unity 검증에서 거부한다. 아이콘 탭에서
교체한 그림을 Unity에 적용하고 새로 내보내면 모든 유형 페이지 미리보기가 갱신된다.
Excel에서 다른 탭의 그림이 실시간으로 바뀌지는 않는다.

그림 자르기·회전·표시 크기는 Sprite 픽셀 편집으로 가져오지 않는다. 이미지를
실제로 변경하려면 외부에서 편집한 PNG/JPEG로 그림을 교체한다.

새 그림은 `Assets/Sprites/BulletWorkbook/`에 내용 해시를 포함한 새 이름으로
가져오고, 해당 `BulletData.cylinderIcon`만 바꾼다. 기존 원본 텍스처와 다른
탄환의 참조를 덮어쓰지 않는다. 원래 Sprite의 pixels-per-unit과 정규화된
pivot을 유지한다. 픽셀 필터는 Point, 압축과 mipmap은 끈다.

탄환 필드와 Sprite 참조는 Unity Undo로 복원할 수 있다. 새로 가져온 이미지
파일은 Undo 후에도 남을 수 있으며 다른 참조가 없음을 확인한 뒤 정리한다.
적용은 `SerializedObject`를 통해 수행한다. 현재 작업의 `Typhoon.asset`
변경은 기준 데이터에 포함하며 되돌리지 않는다.

### 초월 준비 데이터

초월 단계는 탄환 등급 및 기본 강화 레벨과 독립적이다. 초기 1~10단계는
입력 편의를 위한 빈 행이며, 확률과 비용은 아직 정하지 않았다. 추가 행으로
확장할 수 있다. 확률은 0~100, 비용은 0 이상의 정수이며 단계가 높아질 때
확률이 증가하면 거부한다.

입력값은 `ProjectSettings/LOADEDTranscendenceDraft.json`에 별도로 저장한다.
이는 설계용 준비 데이터이며 현재 강화 성공률·비용·세이브에 적용되지 않는다.
파일 변경은 Unity Undo 대상이 아니며 Git으로 복원한다. 초월 런타임 구현 때
실제 소유자와 저장·실패 규칙을 확정한 뒤 연결해야 한다.

## 현지화 편집

원본 에셋·장면·프리팹의 문자열과 코드 문구를 모았다. `ko`는 현재 원문,
`en`은 영어 번역 초안이다. 기존 영어 고유명·제목·숫자 등은 원문을 유지한다.
`Review`는 번역 초안을 검토할 단계이며 최종 승인됐다는 뜻이 아니다.

`분류`, `원본 위치`, `필드`, `문맥`, `key`로 원문을 추적한다. 같은 문구가
여러 곳에 있더라도 서로 다른 문맥에서 바뀔 수 있으므로 키는 분리한다.
에셋은 GUID·오브젝트 fileID·프로퍼티 경로, 코드는 파일·문구 해시·동일 문구
출현 순서로 키를 만든다. 에셋 이름만 바뀌면 키가 유지된다. 코드 문구 자체가
바뀌거나 같은 문구의 배치가 바뀌면 키 이전을 검토한다.

- 공백을 자동으로 Trim하거나 줄바꿈을 합치지 않는다.
- 서로 다른 효과는 서로 다른 줄로 유지한다.
- `{0}`, `{attempt}`, `{0:0.##}` 등은 정확한 토큰을 보존한다.
- 숫자·변수의 위치는 영어 어순에 따라 바꿀 수 있다.
- 색상·굵기·크기 태그가 누락되면 가져오기를 차단한다.
- 앞뒤 공백이나 줄 개수가 달라지면 검토 경고를 표시한다.
- 실제 줄바꿈 대신 문자열 `\n`을 입력하면 거부한다.
- 빈 번역, 중복·알 수 없는 키, 원본 키 삭제는 거부한다.
- 검토 상태는 `Draft`, `Review`, `Approved`이며 Shared Table의 Comment
  메타데이터에 저장한다.

Unity Localization 패키지의 `LOADED` String Table Collection과 한국어·영어
Locale이 번역의 Unity 저장소다. 테이블은 `Assets/Localization`에 있다.
가져오기는 테이블만 바꾸며 원본 ScriptableObject 설명이나 C# 소스를 자동으로
수정하지 않는다. 탄환 워크북의 한국어 설명과 현지화 테이블을 함께 바꿀 때는
양쪽을 명시적으로 검토해야 한다.

### 런타임 연결 범위

이번 산출물은 번역 작성·검증·String Table 적용 도구다. 전체 게임의 언어
선택 UI, 기존 장면 일괄 재저장, 동적 문구의 호출부 변경은 포함하지 않는다.
표의 원본 위치를 바탕으로 후속 연결을 진행한다.

정적 UI는 `LocalizeStringEvent`를 연결하고 `OnUpdateString`을 TMP/UI Text의
public text setter에 등록한다. 코드에서 덮어쓰는 텍스트에는 정적 연결만 해서는
안 된다. 동적 문구는 표에 기록된 변수 표현식을 전달하고, 특히 StringBuilder
조각 문구는 주변 문장과 함께 연결한다. `{attempt}`와 같은 이름 있는 변수는
Smart String 설정과 변수 바인딩을 함께 구현해야 한다. 전체 UI의 영어 레이아웃,
넘침, 폰트 글리프는 런타임 연결 후 각 화면에서 확인한다.

## 구현과 재추출

- `LoadedWorkbook`: OOXML ZIP/XML 읽기·쓰기와 포함 이미지 처리. 별도 XLSX
  라이브러리 설치 없이 Unity Editor에서 동작한다.
- `BulletBalanceWorkbook`: 탄환 검증·변경 계산·선택 적용의 소유자.
- `BulletWorkbookLayout`: 유형·등급별 편집 화면을 기존 검증 모델로 변환하며,
  아이콘의 단일 입력 위치와 유형 탭의 그림 보호를 관리한다.
- `LoadedLocalizationWorkbook`: 번역 검증과 Unity String Table 적용의 소유자.
- `LoadedAuthoringWindow`: 파일 선택과 변경 검토 UI. 게임 규칙을 소유하지 않는다.
- `Tools/Authoring/localization.json`: 원본 위치와 번역 초안의 추출 카탈로그.
- `Tools/Authoring/translations.json`: 한국어 문구별 번역 매핑.

새 문구 추출용 `Capture.cs`와 `CodeCapture.cs`는 Unity Pipeline의 `run_script`로
실행한다. 장면은 preview scene으로 읽고 저장하지 않는다. 코드 추출은 C# 구문
트리로 문자열 연결과 보간 변수를 묶는다. 정규식·문자 처리용 내부 문자열은
`localization-excluded.json`에 제외 사유를 기록한다. 에디터 전용 텍스트는
`Editor` 분류로 구분한다. 추출 후 Python 준비·번역 스크립트를 실행하고 기존
번역 및 키 변경을 검토한다. 번역되지 않은 새 한국어 문구는 자동으로 영어인
것처럼 채우지 않고 스크립트가 보고한다.

`build-workbooks.mjs`는 최초 배포용 워크북의 서식을 만드는 보조 도구다.
일상적인 내보내기·가져오기는 Unity 도구만으로 가능하다.

## 검증

빠진 아이콘, 효과 삭제, 번역 변수·태그 검증, 테스트용 탄환의 수치·아이콘 적용과
Undo를 확인한다. 실제 작업에서는 최종 워크북을 검증하고 적용 전후 diff도 확인한다.

### 12개 유형 분류

- v3는 기획 백업의 12개 유형을 채택해 60개 탄환을 빠짐없이 분류한다.
- 기존 v2의 `Normal`, `Shotgun`, `Debuff` 내부 값은 직렬화 호환을 위해 유지하고
  표시명과 시트명만 각각 표준, 산탄, 상태이상으로 바꾼다.
- 새 내부 값은 `Kinetic`, `Combo`, `Economy`, `Growth`, `Blood`이며 기존 값 뒤에
  추가한다. v2 워크북은 이전 7개 시트 구조로 계속 읽을 수 있다.
