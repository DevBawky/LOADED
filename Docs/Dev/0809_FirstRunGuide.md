# 첫 플레이 노드맵, 전투, 장소 가이드

## 개요

새 게임의 첫 노드맵에서 경로 선택 가이드를 표시하고, 첫 번째로 선택한 전투 노드에서 미션형 전투 가이드를 표시한다. 첫 상점, 이벤트, 보물 노드에서는 해당 장소의 핵심 사용법을 짧게 안내한다. 별도 튜토리얼 씬을 사용하지 않고 실제 노드맵과 각 장소의 흐름을 그대로 사용한다. 저장된 게임을 이어하기로 불러온 경우에는 노드맵 시작 안내를 다시 표시하지 않는다. 사용자가 `다시 보지 않기`를 선택한 경우에는 이후 새 게임에서도 모든 가이드를 표시하지 않는다.

가이드 설명 카드에는 이미 `StreamingAssets/Videos`에 포함된 조작 영상을 재사용한다. 설명을 확인하고 `미션 시작`을 누르면 카드는 상단 미션 바로 축소되며, 실제 행동이 성공했을 때만 다음 단계로 진행한다.

Battle에서 가이드 설명 카드가 열려 있는 동안에는 Duel Clock의 자연 충전과 HUD 연출을 정지한다. 카드를 닫아 미션 바로 축소하면 즉시 다시 진행하며, 일반 툴팁과 전투 연출은 Duel Clock을 정지시키지 않는다.

## 노드맵 가이드

새 게임마다 노드맵의 첫 경로 선택 전에 다음 세 페이지를 표시한다. 과거 런에서 노드맵 가이드를 완료했더라도 새 런의 노드맵 저장 상태가 첫 선택 상태이면 다시 표시한다.

1. 현재 위치에서 이어진 밝은 경로를 따라 이동한다는 전체 구조
2. 시작, 일반 전투, 정예 전투, 상점, 이벤트, 보물, 보스 노드의 의미
3. 이동 가능한 밝은 노드에 마우스를 올려 설명을 확인하고 왼쪽 클릭으로 이동하는 방법

마지막 두 페이지에서는 현재 시작 노드에서 실제로 선택 가능한 첫 노드를 강조한다. 가이드는 노드맵 진행이나 선택 결과를 소유하지 않으며, 안내가 닫힌 뒤 기존 `NodeMapSystem`이 클릭과 씬 이동을 처리한다.

노드 아이콘은 경로 `LineRenderer`보다 정렬 순서가 한 단계 높은 전용 Canvas에서 렌더링한다. 가이드 루트는 노드맵 경로와 아이콘보다 높은 전용 Canvas 정렬 순서를 사용한다. 로딩 및 일시정지 오버레이는 그보다 높은 기존 최상위 정렬 순서를 유지한다.

노드맵은 진행도 약 1/2에 보물 전용 열을 하나만 확정 배치한다. 진행도 약 1/3, 2/3, 보스 직전에는 상점 전용 열을 하나씩 확정 배치한다. 각 전용 열의 모든 노드가 해당 장소이므로 어느 경로를 선택해도 보물상자 한 번과 상점 세 번의 방문 기회를 얻는다. 확정 열은 다른 위치로 이동하지 않으며, 첫 번째 플레이 가능 열은 항상 일반 전투로 유지한다.

상점과 보물은 확정 전용 열에서만 등장하며 일반 노드 추첨으로 추가 생성되지 않는다. 따라서 `NodeMapSettings > Generation Rules`의 Shop 및 Treasure `Weight`, `Minimum Count`, `Maximum Count` 값은 생성에 사용하지 않는다.

## 전투 미션

전투 가이드는 `StageData.Battles` 배열의 0번 전투에 고정하지 않는다. 노드맵 저장 상태에서 아직 완료된 전투 노드가 없고 현재 선택된 노드가 일반 전투, 정예 전투 또는 보스일 때 첫 전투로 판정한다. 따라서 첫 노드가 `Stage 1 Entry 2`나 `Stage 1 Entry 3`을 선택해도 동일하게 시작한다.

미션에 들어가기 전 다음 6개의 시스템 안내 페이지를 표시한다.

1. 시간과 유료 행동으로 충전되고 100%마다 적 행동 카운트를 만드는 Duel Clock
2. 적 공격 준비 효과음, 붉은 행동 타일 패널, 원거리 공격 경로와 범위 예고
3. 같은 탄환도 순서에 따라 피해량이 달라지는 핵심 탄환 전략
4. 탄환별 유효 사거리, 공격 방향과 전방 차단 관계
5. 추가 처치 없이 8카운트가 지나면 종료되는 콤보 게이지
6. 표식, 독, 기절, 약화 디버프의 효과

디버프 종류 안내의 아이콘 툴팁은 가이드 카드보다 높은 전용 Canvas 정렬 순서를 사용한다. 포인터가 아이콘에서 빠져 툴팁이 잠시 숨겨져도 가이드용 정렬 컨텍스트를 유지하고, 일반 전투 툴팁을 열 때 기존 정렬로 복구한다. 일시정지와 로딩 오버레이는 툴팁보다 높은 최상위 순서를 유지한다.

탄환 순서는 이 게임의 핵심 전략으로 별도 시스템 페이지와 실제 순서 변경 미션에서 반복 강조한다. 동일한 탄환 조합도 앞서 발사된 탄환, 남은 탄환, 누적 효과의 연계 순서에 따라 각 탄환과 최종 피해량이 달라질 수 있음을 안내한다.

1. 이동 1회
2. 회전 1회
3. 대기 1회
4. 적 행동 아이콘 확인
5. 장전 3회
6. 실린더 탄환을 우클릭해 약실에서 1발 제거
7. 탄환 정보 창에서 피해, 사거리, 치명타, 특수 효과 확인
8. 실린더 탄환 순서 교환
9. 실린더 탄환에 마우스를 올려 적 피해 예상치 표시
10. 지급된 전기충격 아이템 사용
11. 실제 발차기 성공
12. 실린더 발사

다음 기존 영상을 단계별로 사용한다.

- `Movement.mp4`
- `Rotate.mp4`
- `Reload.mp4`
- `Switch_Bullet_Queue.mp4`
- `Show_Expectation.mp4`
- `Kick.mp4`
- `Shoot.mp4`

대기 미션은 S 키 또는 대기 버튼으로 실제 Duel Clock 진행 행동을 했을 때 완료된다. 약실 제거 미션은 장전 3회 직후에 진행하며, 실린더 탄환을 우클릭해 실제 제거에 성공했을 때만 완료된다. 제거한 탄환은 파괴되지 않고 사용한 탄환 순환으로 이동하며 Duel Clock을 충전하지 않는다. 한 발을 제거한 뒤에도 다음 순서 교환 미션에 필요한 탄환 2발이 남는다. 탄환 정보 읽기 미션은 실린더 탄환이나 다음 탄환의 유효한 상세 툴팁이 실제로 열렸을 때 완료된다. 실린더 순서 조작은 드래그를 시작한 것만으로 완료되지 않고 실제 탄환 교환이 성공해야 한다. 피해 예상치도 유효한 적을 대상으로 예상 체력 표시가 생성된 경우에만 완료된다. 발차기와 아이템 사용 역시 효과가 성공한 경우만 인정한다.

발차기 안내에는 사용 후 유료 행동 3회의 재사용 대기시간, 적끼리 충돌했을 때 양쪽이 받는 피해, 공격 범위 이탈과 사선 정리를 위한 위치 조작 활용법을 포함한다.

키보드 키와 마우스 입력 표기는 가이드 본문에서 빨간색으로 강조한다.

## 아이템 가이드

첫 전투 가이드의 아이템 미션을 시작할 때 기존 `StunAll` 데이터인 `전기충격`을 빈 인벤토리 슬롯에 1개 지급한다. 아이템 슬롯 클릭 또는 숫자 `1/2/3`을 안내하며 실제 아이템 사용 성공 시 완료한다.

플레이어가 가이드보다 먼저 아이템 사용법을 발견했다면 완료 상태를 바로 저장하여 뒤늦게 가이드가 나타나지 않게 한다. 전투 가이드가 중단된 예외 상황에서는 기존 조건부 아이템 가이드가 보조 경로로 동작한다.

## 첫 상점 투어

새 게임마다 첫 상점 진입 시 구매를 강제하지 않는 위치 안내형 투어를 표시한다.

상점 전용 Canvas의 `Panel | Shop`을 가이드 설치 기준으로 사용하며, 공용 스테이지 제목은 `마을. 상점`으로 고정한다.

1. 탄환, 아이템 상품 영역
2. 탄환 관리 버튼
3. 인벤토리와 아이템 판매
4. 상품 새로고침
5. 다음 전투 버튼

상품 안내에는 `Shop_Purchase.mp4`와 `Shop_Idle.mp4`를 재사용한다.

## 첫 이벤트 안내

새 게임마다 첫 이벤트 노드 진입 시 두 페이지를 표시한다.

1. 제목과 상황 설명을 읽고 선택에 따라 결과가 달라진다는 안내
2. 선택지에 비용, 조건, 확률이 포함될 수 있으며 선택 후 결과를 확인한다는 안내

가이드는 이벤트의 선택 가능 여부나 결과를 판정하지 않는다. 안내를 마치거나 건너뛴 뒤 기존 `EventSceneController`가 선택과 결과 처리를 계속 소유한다.

## 첫 보물 안내

새 게임마다 첫 보물 노드 진입 시 두 페이지를 표시한다.

1. 보물상자를 클릭해 유물 후보를 표시하는 방법
2. 유물 툴팁을 확인하고 후보 중 하나를 선택하는 방법

가이드는 보상 후보나 획득 상태를 변경하지 않는다. 기존 `TreasureSceneController`와 유물 시스템이 선택 및 획득을 처리한다.

## 저장과 건너뛰기

다음 `PlayerPrefs` 키는 가이드 완료, 최초 가이드 필수 시청 여부 및 예외적인 보조 아이템 가이드 처리에 사용한다. 노드맵과 첫 전투·상점·이벤트·보물 가이드는 새 게임의 노드맵 진행 상태를 기준으로 판정하므로 과거 완료 여부와 관계없이 새 런에서 다시 표시한다.

```text
loaded.guide.combat.v1
loaded.guide.item.v1
loaded.guide.shop.v1
loaded.guide.node_map.v1
loaded.guide.event.v1
loaded.guide.treasure.v1
loaded.guide.disabled.v1
loaded.guide.first_run_started.v1
```

플레이어에게 최초로 자동 시작되는 가이드는 필수 시청이다. 이 세션에서는 `건너뛰기`, 닫기, `다시 보지 않기`를 숨기고 ESC 입력도 소비하여 모든 페이지를 확인해야 한다. 일반적으로 새 게임의 첫 노드맵 가이드가 이에 해당하며, 노드맵을 거치지 않은 예외적인 시작 흐름에서는 처음 시작된 다른 가이드가 같은 규칙을 적용받는다.

최초 필수 세션을 마친 뒤 각 설명 카드에는 `이전`, `건너뛰기`, `다시 보지 않기` 버튼을 제공한다. 시스템 및 장소 안내에서는 앞 페이지로 이동하며, 완료한 전투 미션은 행동을 다시 요구하지 않는 설명 검토 모드로 보여준다.

`건너뛰기`는 현재 런에서 진행 중인 가이드만 종료하므로 다음 새 게임에서는 다시 나타난다. `다시 보지 않기`는 노드맵, 전투, 아이템, 상점, 이벤트, 보물 가이드를 모두 영구 비활성화한다. 미션 바에서도 두 종료 방식을 선택할 수 있다. 필수 세션이 아닌 경우 ESC는 현재 열린 가이드를 건너뛰는 동작만 수행한다.

새 게임에서는 별도 초기화 없이 전체 가이드가 다시 표시된다. `다시 보지 않기` 상태를 포함해 모든 완료 키를 비우려면 `FirstRunGuideController.ResetSavedProgress()`를 호출한다.

노드맵 안내와 첫 전투 노드 판정에 회피·무방비 안내가 추가된 콘텐츠 버전 4에서는 `loaded.guide.content_version`을 사용한다. 이전 버전을 처음 실행하면 기존 완료 및 `다시 보지 않기` 키를 한 번만 초기화하고 버전 4를 저장한다. 따라서 이전에 가이드를 영구 비활성화했던 사용자도 다음 새 게임에서 개편된 가이드를 다시 볼 수 있다.

전투 시스템 안내에는 공격 피격 직전 범위를 벗어나 회피하는 법과, 공격에 실패한 적에게 비스택형 `무방비`가 생긴다는 설명이 포함된다. 무방비의 다음 피격 크리티컬 확정, 첫 피격 소모, 공격하지 않고 다른 행동을 했을 때 해제되는 규칙도 같은 페이지와 디버프 종류 페이지에서 함께 안내한다.
