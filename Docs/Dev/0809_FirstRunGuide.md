# 첫 플레이 전투, 아이템, 상점 가이드

## 개요

새 게임을 시작할 때마다 첫 전투에서 미션형 가이드를 표시한다. 별도 튜토리얼 씬을 사용하지 않고 실제 전투 흐름과 현재 런 상태를 그대로 사용한다. 저장된 게임을 이어하기로 불러온 경우에는 진행을 방해하지 않도록 다시 표시하지 않는다. 사용자가 `다시 보지 않기`를 선택한 경우에는 이후 새 게임에서도 표시하지 않는다.

가이드 설명 카드에는 이미 `StreamingAssets/Videos`에 포함된 조작 영상을 재사용한다. 설명을 확인하고 `미션 시작`을 누르면 카드는 상단 미션 바로 축소되며, 실제 행동이 성공했을 때만 다음 단계로 진행한다.

## 전투 미션

미션에 들어가기 전 다음 5개의 시스템 안내 페이지를 표시한다.

1. 플레이어의 턴 소비 행동 직후 적도 다음 턴을 수행하는 턴 구조
2. 적 공격 준비 효과음, 붉은 행동 타일 패널, 원거리 공격 경로와 범위 예고
3. 같은 탄환도 순서에 따라 피해량이 달라지는 핵심 탄환 전략
4. 탄환별 유효 사거리, 공격 방향과 전방 차단 관계
5. 표식, 독, 기절, 약화 디버프의 효과

탄환 순서는 이 게임의 핵심 전략으로 별도 시스템 페이지와 실제 순서 변경 미션에서 반복 강조한다. 동일한 탄환 조합도 앞서 발사된 탄환, 남은 탄환, 누적 효과의 연계 순서에 따라 각 탄환과 최종 피해량이 달라질 수 있음을 안내한다.

1. 이동 1회
2. 회전 1회
3. 약실 교환 1회
4. 적 행동 아이콘 확인
5. 장전 3회
6. 탄환 정보 창에서 피해, 사거리, 치명타, 특수 효과 확인
7. 실린더 탄환 순서 교환
8. 실린더 탄환에 마우스를 올려 적 피해 예상치 표시
9. 지급된 전기충격 아이템 사용
10. 실제 발차기 성공
11. 실린더 발사

다음 기존 영상을 단계별로 사용한다.

- `Movement.mp4`
- `Rotate.mp4`
- `Reload.mp4`
- `Switch_Bullet_Queue.mp4`
- `Show_Expectation.mp4`
- `Kick.mp4`
- `Shoot.mp4`

탄환 정보 읽기 미션은 실린더 탄환이나 다음 탄환의 유효한 상세 툴팁이 실제로 열렸을 때 완료된다. 실린더 순서 조작은 드래그를 시작한 것만으로 완료되지 않고 실제 탄환 교환이 성공해야 한다. 피해 예상치도 유효한 적을 대상으로 예상 체력 표시가 생성된 경우에만 완료된다. 발차기와 아이템 사용 역시 효과가 성공한 경우만 인정한다.

발차기 안내에는 사용 후 3턴 재사용 대기시간, 적끼리 충돌했을 때 양쪽이 받는 피해, 공격 범위 이탈과 사선 정리를 위한 위치 조작 활용법을 포함한다.

키보드 키와 마우스 입력 표기는 가이드 본문에서 빨간색으로 강조한다.

## 아이템 가이드

첫 전투 가이드의 아이템 미션을 시작할 때 기존 `StunAll` 데이터인 `전기충격`을 빈 인벤토리 슬롯에 1개 지급한다. 아이템 슬롯 클릭 또는 숫자 `1/2/3`을 안내하며 실제 아이템 사용 성공 시 완료한다.

플레이어가 가이드보다 먼저 아이템 사용법을 발견했다면 완료 상태를 바로 저장하여 뒤늦게 가이드가 나타나지 않게 한다. 전투 가이드가 중단된 예외 상황에서는 기존 조건부 아이템 가이드가 보조 경로로 동작한다.

## 첫 상점 투어

새 게임마다 첫 상점 진입 시 구매를 강제하지 않는 위치 안내형 투어를 표시한다.

1. 탄환, 아이템 상품 영역
2. 탄환 관리 버튼
3. 인벤토리와 아이템 판매
4. 상품 새로고침
5. 다음 전투 버튼

상품 안내에는 `Shop_Purchase.mp4`와 `Shop_Idle.mp4`를 재사용한다.

## 저장과 건너뛰기

다음 `PlayerPrefs` 키는 현재 런의 완료 및 예외적인 보조 아이템 가이드 처리에 사용한다. 새 게임의 첫 전투와 첫 상점 가이드는 과거 완료 여부와 관계없이 다시 표시한다.

```text
loaded.guide.combat.v1
loaded.guide.item.v1
loaded.guide.shop.v1
loaded.guide.disabled.v1
```

각 설명 카드에는 `이전`, `건너뛰기`, `다시 보지 않기` 버튼을 제공한다. 시스템 안내와 상점 안내에서는 앞 페이지로 이동하며, 완료한 전투 미션은 행동을 다시 요구하지 않는 설명 검토 모드로 보여준다.

`건너뛰기`는 현재 런에서 진행 중인 가이드만 종료하므로 다음 새 게임에서는 다시 나타난다. `다시 보지 않기`는 전투, 아이템, 상점 가이드를 모두 영구 비활성화한다. 미션 바에서도 두 종료 방식을 선택할 수 있다. ESC는 현재 열린 가이드를 건너뛰는 동작만 수행한다.

새 게임에서는 별도 초기화 없이 전체 가이드가 다시 표시된다. `다시 보지 않기` 상태를 포함해 모든 완료 키를 비우려면 `FirstRunGuideController.ResetSavedProgress()`를 호출한다.
