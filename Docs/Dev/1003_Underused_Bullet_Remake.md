# 저사용 탄환 리메이크

## 확정 규칙

| 탄환 | 유형 | 최종 능력 |
| --- | --- | --- |
| 고조탄 | 상태이상 | 명중 시 독·표식·약화·기절 중 하나를 무작위로 부여한다. |
| 공명탄 | 연계 | 직전에 발사한 탄환이 실제로 부여한 상태이상 종류를 명중 대상에게 각각 다시 부여한다. |
| 혼합탄 | 상태이상 | 독·표식·약화를 동시에 같은 스택만큼 부여한다. 기절은 부여하지 않는다. |
| 양산탄 | 성장 | 보유한 노멀·레어 탄환 수에 따라 추가 공격한다. 레벨별 추가 공격 상한을 둔다. |
| 수확탄 | 연계 | 이 탄환으로 적을 처치하면 현재 체력이 가장 낮은 생존 적에게 즉시 다시 발사한다. 레벨별 연쇄 상한을 둔다. 기존 콜렉터를 이름과 아이콘까지 변경한다. |
| 귀환탄 | 관통 | 명중 후 탄환이 플레이어에게 돌아오며 같은 레인의 귀환 경로에 추가 피해를 준다. 기존 독점탄을 이름과 아이콘까지 변경한다. |
| 명품탄 | 성장 | 치명타가 확정된다. 보유한 에이스·레전드리 탄환 수에 따라 치명타 배율이 증가하며 개수 상한을 둔다. |
| 응고탄 | 혈투 | 발사 후 잃은 체력의 일정 비율을 회복한다. 보유한 혈투 탄환 수에 따라 회복 비율이 증가하며 상한을 둔다. 기존 치명타 확률은 유지한다. |
| 비상탄 | 유령 | 발사 후 다음 재장전이 턴을 소모하지 않는다. 기존 장전수탄을 이름·유형·아이콘까지 변경한다. |
| 잭팟탄 | 경제 | 발사마다 한 번 확률을 판정한다. 당첨되면 해당 발사와 추가 공격 전체에 높은 최종 피해 배율을 적용하고 골드를 획득한다. 아이콘도 슬롯머신 콘셉트로 변경한다. |
| 의식 | 혈투 | 발사할 때 최대 체력 1을 지불하고 이번 런 동안 영구 기본 피해를 얻는다. 최대 체력은 1 미만이 되지 않는다. |

## 레벨 수치

표의 값은 기본 / +1 / +2 / +3 순서다.

| 탄환 | 핵심 수치 |
| --- | --- |
| 고조탄 | 무작위 상태이상 1종 2/3/4/5스택 |
| 공명탄 | 복제 상태이상별 1/2/3/4스택 |
| 혼합탄 | 상태이상별 1/1/2/3스택 |
| 양산탄 | 추가 공격 상한 2/3/4/5회 |
| 수확탄 | 연쇄 상한 1/2/3/5회 |
| 귀환탄 | 귀환 피해 40/60/80/100% |
| 명품탄 | 고등급 탄환당 치명타 배율 +0.15/+0.20/+0.25/+0.30, 반영 개수 상한 5/6/7/8개 |
| 응고탄 | 잃은 체력 회복 10/12/15/20%, 혈투 탄환당 +3/+4/+5/+5%p, 상한 30/40/50/60% |
| 비상탄 | 다음 재장전의 턴 소모 제거 |
| 잭팟탄 | 당첨 확률 10/12/15/20%, 최종 피해 ×3/×4/×5/×7, 골드 +3/+4/+5/+7 |
| 의식 | 발사당 영구 기본 피해 +2/+3/+5/+8, 최대 체력 비용 1 |

## 전투·표시 규칙

- 실제 피해와 실린더 호버 예상 피해는 같은 규칙을 사용한다.
- 수확탄의 다음 대상은 매 연쇄 시점에 다시 계산하며, 체력이 가장 낮은 생존 적을 선택한다.
- 귀환탄은 명중 지점에서 플레이어 방향으로 되돌아오는 탄환과 궤적을 표시한 뒤 같은 레인의 생존 적에게 귀환 피해를 적용한다.
- 잭팟 판정은 실제 기본 발사에서 한 번만 수행하며 그 발사로 생성된 추가 공격은 같은 결과를 공유한다.
- 비상탄의 무료 재장전 예약은 실제로 성공한 다음 재장전에서만 소모한다.
- 효과·이름·유형·아이콘을 변경한 뒤에는 모든 상점 풀과 메인 메뉴 도감을 동기화하고 `LOADED_BulletData.xlsx`를 현재 에셋에서 다시 내보낸다.

## 에셋 변경

- `Collection.asset`은 GUID를 유지한 채 `Harvest.asset`으로 이동한다.
- `Monopoly.asset`은 GUID를 유지한 채 `Return.asset`으로 이동한다.
- `Loader.asset`은 GUID를 유지한 채 `Emergency.asset`으로 이동한다.
- 수확탄은 레전드리, 귀환탄은 에이스, 비상탄과 잭팟탄은 레어 등급 테두리를 사용한 64×64 아이콘을 사용한다.

기존 `Bullet_Ideas.md`, `0806_Crescendo_QuickDraw_Remake.md`, `0820_NewBulletSet.md`의 동일 탄환 초기안보다 이 문서와 현재 `BulletData` 에셋을 우선한다.
