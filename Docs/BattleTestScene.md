# 전투 테스트

`Assets/Scenes/BattleTest.unity`는 Battle을 복제한 개발용 테스트 씬이다.
배경, 카메라, 전투 HUD, 탄환/유물/적/보상 처리는 실제 Battle의 구성과 코드를 사용한다.
시작 시 적이 없는 보드가 생성되며, 적을 전부 처치하거나 플레이어가 사망해도 다른 씬으로 넘어가지 않는다.
일반 진행 저장과 통계 기록은 이 씬에서 차단한다. Build Settings에는 포함하지 않는다.

## 실행

Unity 메뉴 **Tools > LOADED > 전투 테스트 > 열기**로 열고 Play한다.
한글 설정 창이 처음부터 열린다. 명령을 외우지 않고 버튼과 입력란으로 조작할 수 있다.
설정 창이 열려 있는 동안 전투는 기존 일시정지 규칙에 따라 멈추고, 입력한 키는 전투 조작에 전달되지 않는다.
F1 또는 **전투로 돌아가기**로 닫으면 기존 Battle 키를 그대로 사용한다.

Battle의 환경이나 카탈로그가 변경되면 Play를 종료하고
**Tools > LOADED > 전투 테스트 > Battle에서 생성 또는 갱신**을 실행한다.
이 명령은 BattleTest를 Battle로부터 다시 생성하므로 테스트 씬에 직접 해둔 편집은 덮어쓴다.
원본 Battle, 프리팹, 데이터 에셋은 수정하지 않는다. 열려 있는 씬의 미저장 변경이 있으면 실행하지 않는다.

## 한글 설정 화면

전투판 위에 두 개의 작은 패널을 띄운다. 패널 제목을 끌면 이동하고,
제목을 두 번 클릭하면 원래 위치로 돌아온다. **접기/펼치기**로 전투판을 넓게 볼 수 있다.
패널을 접어도 설정 창이 열린 동안에는 전투가 일시정지된다. F1로 닫으면 전투를 재개한다.

| 직접 조작 | 결과 |
| --- | --- |
| 도감 탄환 → 내 덱으로 드래그 | 지정한 강화 수치로 탄환 추가 |
| 도감 유물 → 보유 목록 | 유물 획득 |
| 도감 아이템 → 원하는 슬롯 행 | 그 슬롯에 아이템 넣기 |
| 도감 적 → 전투판의 빈칸 | 해당 칸에 적 배치. 끄는 동안 좌표와 배치 가능 여부 표시 |
| 보유 탄환·유물·아이템·적 → 왼쪽 아래 제거 영역 | 해당 항목 제거. 마지막 탄환 보호 및 실제 소유자 규칙 유지 |
| 전투판의 칸 클릭 | 좌표 선택. 적이 있으면 체력·상태 조절 대상으로 선택 |
| Shift를 누르고 전투판 빈칸 클릭 | 플레이어 위치 이동 |
| 탄환·유물 등 항목 칸 전체에 마우스 올리기 | 이름·아이콘·배경·빈 여백 어디든 잠시 후 상세 효과와 조작 안내 툴팁 |
| 항목 우클릭 | 강화·설명·처치·제거 등 해당 항목의 조작 메뉴 |
| 도감 항목 더블클릭 | 빠른 추가. 적은 선택 좌표에 생성, 아이템은 입력된 슬롯에 넣기 |
| 탄환 칸 클릭 / 수치 편집 | 선택한 탄환의 단계별 원본 수치 편집 창 열기 |
| 보유 탄환 / 적 더블클릭 | 원본 수치 편집 / 조절 대상 선택 |
| 숫자 입력란 위에서 휠 | 1씩 증감. Shift는 10씩, Ctrl은 100씩. 적용 버튼을 누르면 확정 |
| Esc / F1 / 다른 탭 선택 | 진행 중인 드래그와 팝업 취소 |

빈 공간이나 다른 종류의 대상에 놓은 드래그는 아무것도 변경하지 않는다.
보드 바깥·점유된 칸·가득 찬 덱에는 추가하지 않는다. 드래그와 버튼은 같은 검증 경로를 사용한다.
행의 빠른 조작 버튼은 마우스를 올렸을 때만 표시한다. 목록 스크롤은 마우스 휠을 사용한다.

| 탭 | 조작 |
| --- | --- |
| 탄환 · 내 덱 | 왼쪽에 보유 탄환 한 발당 한 행을 표시한다. 강화 증가·감소, 수치 편집, 제거 버튼을 사용할 수 있다. |
| 유물 | 보유 유물 제거, 도감 검색·설명 확인·추가 |
| 적 배치 · 상태 | 원하는 적을 지정 좌표에 생성하거나 여러 적을 무작위 생성. 배치된 적의 조절·처치·제거 가능 |
| 아이템 | 슬롯 선택·비우기, 도감에서 교체, 모든 슬롯 무작위 설정 |
| 플레이어 · 보드 | 현재·최대 체력, 골드와 무작위 골드, 위치 이동, 보드 크기, 무작위 수 초기값 설정 |
| 명령 · 도움말 | 명령 입력, 한글 도움말, 출력 기록 확인 |

탄환 도감은 한글 이름·유형·효과로 검색할 수 있다. 칸에 마우스를 올리면 상세 효과를 보여준다.
검색 아래에서 **등급(일반·희귀·에이스·전설)**과 **탄환 유형**을 각각 선택할 수 있다.
검색어와 두 분류 조건은 함께 적용되며, 전체를 선택하면 해당 분류 제한을 해제한다.
유물은 실제 데이터에 등급 필드가 없으므로 **지속형·소모형**과 **효과(공격·이동·장전·상태이상·생존·재화·성장 등)**로 분류한다.
분류 선택은 탄환과 유물 탭별로 보관한다. 보유 목록은 전체를 보여주며 도감만 필터링한다.
아래 **추가 강화**에 0~3을 입력하면 해당 단계의 설명을 볼 수 있다.
각 행의 **추가** 또는 아래 **선택 탄환 추가**로 그 단계의 탄환을 덱에 넣는다.
목록과 적 상세 영역은 마우스 휠로 스크롤한다.

같은 종류의 탄환도 고유 번호를 가진 별도 행으로 표시하므로 원하는 한 발만 조절할 수 있다.
행 아래에는 덱·장전됨·사용 후 대기 위치가 표시된다. 마지막 한 발은 수동 제거할 수 없으며,
총 20발이 되면 추가 버튼이 비활성화된다. 강화 한계에 도달한 버튼도 비활성화된다.
개발자 창에는 장전·실린더 채우기 기능을 제공하지 않는다. 장전은 F1로 창을 닫고 실제 전투 조작으로 진행한다.
강화 및 체크포인트 복원에서는 에셋 이름을 먼저 확인한다. 같은 내부 ID를 공유하는 기존 탄환도 다른 종류로 바뀌지 않는다.

적 목록의 **조절**을 누르면 해당 적의 좌표와 현재 체력이 입력되고 상태이상 중첩을 표시한다.
**변경 수치**를 입력한 뒤 체력·보호막·피해 버튼을 누른다.
상태이상 종류 버튼을 눌러 표식·독·기절·약화·무방비를 선택하고 중첩을 적용한다.
적 처치는 실제 사망·보상 처리를 거치고, 제거는 보상 없이 정리한다.

적 탭의 왼쪽 아래에서 **전멸 시 자동 보충**을 켜거나 끄고 **점유율 (%) → 점유율 적용**으로 설정한다.
**최대 횟수** 슬라이더는 0~10회로 설정한다. 0은 무한이며, 1~10은 실제로 적을 한 마리 이상
생성한 자동 보충만 1회씩 사용한다. 제한을 바꾸면 사용 횟수는 0회부터 다시 시작한다.
기본값은 꺼짐·50%·무한(0)이다. 적이 0마리가 되면 진행 중인 사격·연쇄 효과·적 행동이 모두 끝난 뒤
무작위 종류의 적을 무작위 빈칸에 한 번 배치한다. 켤 때 이미 빈 보드라면 곧 보충한다.
적이 남아 있는 동안에는 부족한 수만큼 계속 추가하지 않는다. 처치뿐 아니라 제거·모두 정리·보드 재생성 후에도 적용되므로
빈 보드를 유지하려면 자동 보충을 끈다. 플레이어가 사망한 동안에는 기다렸다가 회복 후 보충한다.
점유율은 전체 타일 수 기준으로 계산해 올림한다(14칸 × 50% = 7마리, 15칸 × 50% = 8마리).
플레이어·폭탄·적·이동 예약 칸은 제외하며 실제 빈칸까지만 배치한다. 0%는 생성하지 않는다.
점유율은 적의 **생성 수**만 정하며, 생성된 적의 원래 체력이나 방어 능력은 바꾸지 않는다.
따라서 탄환마다 같은 수의 처치를 재현하려면 적 도감의 자동 스폰 대상을 해당 탄환이 확실히
한 번에 처치할 수 있는 한 종류(예: 지게꾼)로 제한한다. 적이 한 명이라도 생존하면 전멸이 아니므로
다음 탄환 전에 새 무리가 보충되지 않으며, 이때 콤보는 실제 처치 수만 증가한다.
이 설정은 테스트 체크포인트에 함께 보관되며 일반 런 저장에는 추가되지 않는다.

오른쪽 **적 도감**이 자동 스폰 대상 목록을 겸한다. 각 행에 자동 스폰 켜짐/꺼짐을 항상 표시하며,
행에 마우스를 올린 뒤 **자동 켜짐 / 자동 꺼짐** 버튼으로 개별 허용 여부를 전환한다.
기본값은 일반 적 `true`, 보스(현재 `BigBarrel` 행동 유형)는 `false`다.
전멸 후 자동 보충과 **무작위 생성**은 켜진 적만 뽑는다. 전부 끄면 생성하지 않고 대상 없음 안내를 표시한다.
직접 생성·드래그 배치는 제한하지 않는다. 목록 변경은 이미 배치된 적을 제거하지 않으며,
빈 보드에서 대상을 다시 켜면 활성화된 자동 보충이 재개된다.
허용 목록은 `BattleTestController`가 관리하고 체크포인트에 함께 보관한다. Play를 새로 시작하면 기본값으로 돌아간다.
명령은 `spawnpool`로 목록 조회, `spawnpool <적 번호 또는 이름> on|off`로 개별 설정한다.

상단에는 적 자동/수동, 한 사이클 진행, 무적, 상태 저장·복원 버튼이 있다.
조작 결과와 잘못된 입력 안내는 화면 아래에 한글로 표시한다.
명령 입력은 선택 사항이며, 기존 디버그 단축키도 모든 탭에서 사용할 수 있다.
버튼·입력란·분류 드롭다운에 잠시 마우스를 올리면 기능, 적용 범위와 조작 방법을 한글 툴팁으로 안내한다.

## 탄환 원본 수치 편집

1. 내 덱 또는 도감의 탄환 칸을 클릭하거나 **수치 편집**을 선택한다.
2. **편집할 강화 단계**에서 기본(0), +1, +2, +3 중 하나를 선택한다.
3. 대미지(0 이상 정수), 치명타 확률(0~100%, 소수 가능), 치명타 대미지 배율(1 이상), 사거리(1~10칸)를 입력한다.
4. **원본에 저장**을 누르면 해당 `BulletData`의 해당 단계에만 저장된다. 치명타 배율 2.5는 기본 피해의 250%다.

값을 입력하는 동안에는 전투 데이터가 바뀌지 않는다. 저장 즉시 같은 탄환 원본을 사용하는 모든 인스턴스가
새 수치로 계산되며, Play를 종료해도 유지된다. 다른 강화 단계·효과·종류·개별 탄환의 스택은 변경하지 않는다.
**입력 되돌리기**는 미저장 입력만 버린다. 다른 탄환/단계를 선택하면 그 원본을 다시 읽으므로 미저장 입력을 버린다.
체크포인트 복원은 탄환 원본 수치를 되돌리지 않는다. 원본 저장은 Unity 에디터에서만 지원한다.
잘못된 값과 행동 진행 중 저장은 거부하며, 성공·오류는 편집 창 아래에 표시한다.

저장 시 기존 작성 도구로 `outputs/authoring-20261002/LOADED_BulletData.xlsx`도 다시 내보내고 검증한다.
직전 엑셀은 `Logs/BattleSandbox/WorkbookBackups/`에 보관한다. 엑셀이 열려 있어 교체할 수 없으면
탄환 원본 저장 성공과 엑셀 실패를 구분해서 표시한다. 엑셀을 닫고 다시 저장하면 동기화된다.
숫자 변경은 기존 카탈로그의 같은 에셋 참조에 즉시 반영된다. 탄환 추가·제거 등 목록 변경은 기존
`Sync All Bullet Pools`와 테스트 씬 갱신을 사용한다.

## 카탈로그와 좌표

`list bullet`, `list enemy`, `list relic`, `list item`으로 사용 가능한 에셋을 조회한다.
`list bullet 독`처럼 검색어를 붙일 수 있다. 출력된 숫자 ID, 에셋 이름, 표시 이름을 입력할 수 있다.
여러 에셋이 일치하면 정확한 이름이나 ID를 사용한다. 공백이 있는 이름은 큰따옴표로 감싼다.
카탈로그 ID는 에셋 이름순이며 카탈로그를 재생성하면 바뀔 수 있다.

모든 인덱스는 **0부터** 시작한다. 좌표는 항상 **칸 번호, 레인 번호** 순서다.
칸 번호는 왼쪽부터, 레인 0은 기존 Battle의 앞쪽 레인이다.
`owned`는 보유 탄환의 고유 ID와 장전 순서, 보유 유물/아이템의 인덱스를 출력한다.
`enemies`는 적의 좌표·체력·보호막·상태 스택과 공격 준비 여부를 출력한다.

## 명령

| 명령 예시 | 동작 |
| --- | --- |
| `board 9 2` | 레인당 9칸, 2레인 생성. 적·폭탄·드롭 제거, 플레이어 중앙 이동 |
| `bullet add 0 3` | 카탈로그 0번 탄환을 +3으로 덱에 추가 |
| `deck set 0 2` | 덱 전체를 지정한 +2 탄환 하나로 교체 |
| `bullet level 0 3` | 보유 ID 0번 탄환의 강화 수치를 +3으로 설정 |
| `bullet remove 0` | 보유 ID 0번 탄환 제거 (최소 1개 유지) |
| `relic add 0` / `relic remove 0` | 카탈로그 유물 추가 / 보유 인덱스의 유물 제거 |
| `spawn 0 5 0` | 카탈로그 0번 적을 5번 칸, 0번 레인에 생성 |
| `random 3` | 서로 다른 빈칸에 무작위 적 3마리 생성 |
| `refill on 50` / `refill off` | 전멸 시 전체 타일의 50%만큼 자동 보충 / 끄기 |
| `refill percent 25` | 켜짐·꺼짐 상태를 유지하며 점유율만 25%로 변경 |
| `refill limit 3` / `refill limit 0` | 자동 보충을 최대 3회로 제한 / 무한으로 설정하고 사용 횟수 초기화 |
| `enemy kill 5 0` | 해당 적을 정상 사망·보상 경로로 처치 |
| `enemy remove 5 0` | 해당 적을 보상 없이 제거 |
| `enemy hp 5 0 10` | 적 체력 설정 (1부터 해당 적 최대 체력까지) |
| `enemy shield 5 0 50` | 적 보호막 설정 |
| `enemy damage 5 0 20` | 보호막과 피격 처리를 거쳐 공격 피해 적용 |
| `status 5 0 독 10` | 적 독 스택 설정 (추가가 아닌 지정 수치로 변경) |
| `status 5 0 표식 0` | 적 표식 제거 |
| `clear` | 모든 적·폭탄·드롭 제거 |
| `player 2 0` | 플레이어를 빈칸으로 이동, Tempo·이동 효과 없음 |
| `hp 25 150` | 플레이어 현재 체력 25, 최대 체력 150 |
| `hp 0` | 플레이어 사망 상태 테스트. 이후 `hp 100`으로 복구 가능 |
| `gold 999` / `gold random 10 500` | 재화 설정 / 범위 내 무작위 설정 |
| `item set 0 2` | 아이템 0번 슬롯을 카탈로그 2번 아이템으로 설정 |
| `item remove 0` / `item random` | 슬롯 비우기 / 세 슬롯 무작위 설정 |
| `ai off` / `ai on` | 적 사이클 수동 진행 / 기존 Cylinder Tempo 진행 |
| `step` | Tempo를 채워 적 사이클 한 번 예약. 콘솔을 닫으면 진행 |
| `god on` / `god off` | 피해에 대한 무적 켜기/끄기 |
| `seed 1234` | Unity RNG 상태 초기화 |
| `checkpoint` / `reset` | 현재 상태 메모리 저장 / 복원 |
| `help` | 명령 목록 |

보드 제한은 레인당 2~30칸, 1~6레인이다. 큰 보드도 Battle의 카메라 동작을 유지한다.
탄환 강화는 0~3, 총 보유 수는 20, 아이템 슬롯은 0~2다.
상태 종류는 `표식`, `독`, `기절`, `약화`, `무방비`이며 무방비는 0/1이다.
기존 영문 이름 `Mark`, `Poison`, `Stun`, `Weakness`, `Exposed`도 입력할 수 있다.
직접 설정한 독은 플레이어 기여 피해로 처리된다.
재화 설정은 획득 이벤트를 발생시키지 않으며, 획득 트리거 테스트에는 실제 처치 보상을 사용한다.
무적은 피해를 막으며 체력/최대 체력을 지불하는 탄환 효과까지 무효화하지 않는다.

## 반복 테스트

1. `board 9 2`, `deck set ...`, `bullet add ...`, `spawn ...`, `status ...`로 구성한다.
2. 필요하면 `ai off`, `god on`으로 조건을 고정한다.
3. Ctrl+F5로 체크포인트를 만든다.
4. F1을 닫고 실제 장전·이동·사격을 시험한다. 수동 AI에서는 F3으로 적 사이클을 진행한다.
5. 행동 종료 후 F5로 같은 구성을 복원한다.

체크포인트는 보드 크기, 플레이어 위치/방향/체력/상태, 덱과 탄환 상태,
유물, 아이템, 재화, 적 준비 행동/상태, 폭탄, Tempo, 무적/AI 모드와 자동 보충 설정을 보관한다.
시작 시 빈 보드 상태를 자동으로 저장한다. Play를 종료하면 사라진다.
복원 시 드롭 아이템과 화면의 피해/처치 누계는 지운다.
애니메이션 진행률, 날아가는 투사체와 입력 기록을 재생하는 기능은 아니다.
연출도 RNG를 소비하므로 같은 seed나 체크포인트가 프레임 단위로 동일한 재현을 보장하지 않는다.

## 구현 경계

`BattleTestController`는 테스트 명령을 실제 상태 소유자에게 전달하고 메모리 체크포인트를 조립한다.
`BattleTestCommandRouter`는 명령 해석, `BattleTestConsole`은 단축키·명령 입력과 결과 표시를 담당한다.
`BattleTestGui`는 실제 소유자의 상태를 조회하여 목록과 설명을 표시하고,
`BattleTestListRow`와 `BattleTestCommandButton`은 버튼 의도를 같은 명령 경로로 전달한다.
`BattleTestInteractions`는 드래그·툴팁·우클릭과 화면 좌표의 보드 투영을 담당한다.
보드 판정은 실제 Battle 카메라와 보드 평면을 사용한다. 유효한 드롭도 명령 검증을 거친다.
`BattleTestDropTarget`, `BattleTestWindowHandle`, `BattleTestNumberField`는 각각 드롭 대상,
패널 이동·접기, 숫자 휠 입력만 담당한다. 드래그 상태와 팝업은 닫기·탭 전환·명령 실행 시 정리한다.
별도의 전투 상태를 GUI에 저장하지 않는다. `BattleTestGuiBuilder`는 한글 uGUI 구조를 생성한다.
개발자 Canvas의 표시 순서는 29000으로 유지한다. TMP 드롭다운 목록(30000)과
바깥 클릭 차단막(29999)이 패널보다 앞에 있어야 분류·강화 단계 목록을 보고 선택할 수 있다.
덱·유물·아이템·재화는 기존 소유자의 API로 변경한다.
`BattleTestBulletAuthoring`은 미저장 입력만 가지며, 명시적인 원본 저장은 Editor 전용
`BattleTestBulletAssetWriter`가 `SerializedObject`와 `AssetDatabase.SaveAssetIfDirty`로 수행한다.
`BulletInstance`는 원본 수치를 직접 조회하므로 저장 때문에 인스턴스를 교체하거나 덱을 복원하지 않는다.
기능 툴팁은 `BattleTestControlTooltip`과 `BattleTestHelpText`가 제공한다.
`WaveManager`의 테스트 초기화 경로는 자동 스폰과 전투 완료 전환을 제외하고 기존 적 생성/행동/보상 경로를 사용한다.
자동 보충은 한 물리 탄환의 연쇄·조건부 효과가 모두 끝난 뒤 실행되어 같은 탄환에는 새 적이 끼어들지 않는다.
실린더에 탄환이 남아 있으면 보충된 적은 바로 다음 물리 탄환부터 표적이 된다. 사격 밖에서 전멸하면 기존처럼 조작이 안정된 다음 프레임에 보충한다.
`BattleTestContext`는 정확한 테스트 씬 경로에만 적용되는 입력 일시정지·무적 플래그를 제공한다.
일반 Battle에서는 테스트 관련 분기가 비활성이다.

검증: `BattleTestSceneTests`, `BattleTestGuiTests`, `BattleTestInteractionTests`, `BattleTestEnemyRefillTests`, `BattleTestBulletAuthoringTests`,
`CylinderTempoTests`, 관련 덱/유물 테스트와 `SceneIntegrityTests`, `LoadedWorkbookTests`, `BulletPoolIntegrityTests`.
